## What I build

I like small tools that fix one real problem and have no setup cost.

- [magento-llms-txt](https://github.com/rishabhg16/magento-llms-txt) generates an llms.txt file for a Magento 2 store from its GraphQL API. Pure Python, no dependencies, tested on Python 3.9, 3.11 and 3.13. I checked it against a live store with millions of products, and that is why it skips the slow product counts by default.
